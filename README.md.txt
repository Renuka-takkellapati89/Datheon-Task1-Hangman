# Hangman Game — Python

## Project Description
This project is a command-line Hangman game developed using Python. The player guesses a hidden word one letter at a time before running out of attempts.

## Features
- Random word selection
- Hidden-word display
- Letter-by-letter guessing
- Incorrect guess tracking
- Hangman drawing
- Win and lose detection
- Replay option

## Technologies Used
- Python
- Random module

## How to Run
1. Install Python 3.
2. Open a terminal in the project folder.
3. Run the command:

   `python hangman.py`

## Learning Outcomes
- Python loops and conditional statements
- Strings and lists
- User input handling
- Basic game logic
